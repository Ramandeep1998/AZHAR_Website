Firebase Setup Wizard

Complete each step below. Click Check Status after each one.

Checking setup...

Step 1: Firebase Config

Your js/firebase-config.js must have all Firebase keys filled in.

Step 2: Authentication (Login)

Enable Email/Password sign-in and create an admin user.

Open Authentication Add Admin User

In Sign-in method → enable Email/Password. In Users → Add user with email & password.

Step 3: Firestore Database

Create the database and publish security rules.

Open Firestore Open Rules

Create database → test mode → region asia-south1. Copy rules from firestore.rules in project folder.

Step 4: Storage (Image Uploads)

Enable storage for product image uploads.

Open Storage Open Rules

Get started → test mode. Copy rules from storage.rules in project folder.

Step 5: Test Login

Once all above are green, go to admin login.

Go to Admin Login View Website
